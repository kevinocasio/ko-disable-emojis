# KO Disable Emojis

> Lightweight WordPress plugin to remove core emoji scripts, inline styles, and DNS prefetch links for faster load times.

## Overview

WordPress automatically enqueues emoji scripts and styles on every page load. **KO Disable Emojis** strips out this extra asset bloat while keeping modern native device emoji support fully functional.

## Features

* **Remove Script Bloat:** Blocks emoji detection scripts from loading in the `<head>`.
* **Clean Header:** Strips inline emoji CSS and DNS prefetch calls to `s.w.org`.
* **Zero Front-End Assets:** Pure PHP execution with 0 bytes of extra CSS or JS loaded on public pages.
* **Instant Dashboard Toggle:** Manage and toggle the feature directly from the **KO Plugins** dashboard.

## Installation

1. Click the green **`< > Code`** button at the top of this repository and select **Download ZIP** (or download from [Releases](../../releases)).
2. In your WordPress admin dashboard, navigate to **Plugins -> Add New Plugin -> Upload Plugin**.
3. Choose the downloaded `.zip` file and click **Install Now**.
4. Click **Activate Plugin**.
5. Manage settings directly under the **KO Plugins** dashboard menu.
